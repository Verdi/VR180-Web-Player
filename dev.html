HLS player. In VR it plays test-media/hls/master.m3u8 (side by side, 8K to 4K). In 2D it plays test-media/hls-2d/master.m3u8 (left eye only, 3K, 2K, and 1K). To test another stream, add ?hls= and the stream address to this page's address. Add ?mode=hls.js or ?mode=native to choose how HLS plays. Without it, Safari uses its own HLS, and other browsers use hls.js.

Test options: ?debug shows the video size in the panel title. ?quality=best gives Safari's own HLS only the highest quality (the default is auto). ?no2d plays the side-by-side stream in 2D too, instead of the 2D stream. Join options with &, for example ?debug&quality=best.
